# conformance-journal

The journal settings that [conformance-paper](https://github.com/Open-Scholar-Nexus/conformance-paper) builds against when `oak conformance` tests an oaktree-sapling release. Keep this repo public: builds of pull requests from forks clone it without a token, so making it private breaks every fork preview. See the [conformance docs](https://scholar.nexus/oaktree-sapling/design/conformance).
